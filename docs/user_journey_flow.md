
# 가이 알아? — 유저 여정 플로우 (실제 구현 기준, 2026-09-13)

브라우저로 직접 실행해서 화면마다 스크린샷으로 확인한 결과를 정리했다. 문구는
전부 실제 렌더링된 텍스트를 그대로 옮겼다(디자인 목업이 아니라 지금 코드 기준).

> 스크린샷 파일 자체는 내보낼 방법이 없어서(브라우저 도구가 파일로 저장하는
> 기능을 안 줌) 파일로 첨부하지 못했어 — 대신 대화 중에 화면별로 캡처를 인라인으로
> 계속 보여줬고, 여기 문서는 그 확인 내용을 문구 검토용으로 정리한 거야.

## 전체 흐름

```text
01 첫 화면(/)
  └─ [버튼] → 02 로그인(/login)
                ├─ 카카오 로그인 전: [카카오로 계속하기]
                └─ 로그인 후 표시 이름 없음: 이름 입력 → [이 이름으로 시작하기]
                     └─ → 03 지인 연결(/connect)
                            [공유하기] 또는 [링크 복사] → 지인 링크 전달
                            └─ "이어진 사람 보기 →" → 06

받은 사람이 지인 링크(/invite/{token}) 열면:
04 지인 확인 → [네, 알고 있어요] → 05 연결 완료
                                      ├─ [나도 아는 사람에게 보내기] → 03
                                      └─ [이어진 사람 보기 →] → 06

06 내 연결 메인(/result)
  ├─ [아는 사람에게 보내기] → 03
  ├─ [몇 다리인지 확인할 링크 공유하기 →] → 공유 영역 펼침(화면 07, 같은 페이지 안)
  ├─ "내 연결 보기" → /connections (건너건너 만난 사람들)
  └─ [로그아웃] → 01

공개 링크(/r/{token}) 열면:
08 공개 링크 진입(로그인 여부와 무관하게 먼저 노출) → [몇 다리인지 확인하기]
  ├─ 로그인·이름 설정 필요 → 02 → 원래 /r/{token} 복귀 → 거리 자동 계산
  └─ 로그인·이름 설정 완료 → 거리 계산
       ├─ 찾음 → 09 연결 발견(다크 톤) → [나도 시작하기] → 02, 또는 [결과 공유하기]
       └─ 못 찾음 → 10 연결 미발견 → [나도 시작하기] → 02, 또는 [다시 확인하기]

세션 없이 06/03 등 인증 필수 화면 접근 시 → 자동으로 02(/login)로 리다이렉트
로그인+표시 이름 완료 세션으로 01(/) 접근 시 → 자동으로 06(/result)으로 리다이렉트
```

## 화면별 상세

### 01 · 첫 화면 (`/`)
**목적**: 3초 안에 뭘 하는 서비스인지 이해시키고 시작하게 만든다.

```
가이 알아?
🍊  ?  🍊
나는 누구와 건너건너
아는 사이일까?

아는 사람들과 이어지다 보면
생각지도 못한 사람과 닿을지도 몰라요.

[ 시작해보기 ]

세상은 생각보다 좁대요
몇 사람만 거치면 세상 누구와도
이어질 수 있다는 이야기가 있어요.

개인정보처리방침
```
- 로그인+표시 이름을 이미 마친 사람이 이 주소로 들어오면 이 화면 대신 06으로
  바로 넘어간다(서버에서 판단, 화면이 잠깐이라도 보이지 않음).
- CTA는 사용자 맥락에 따라 의도적으로 구분한다. 최초 방문인 이 화면에서는
  `시작해보기`, 다른 사람의 경험이나 결과를 본 뒤에는 `나도 시작하기`를 쓴다.
- 하단 설명은 서비스 아이디어를 보충하는 작은 카드다. 메인 질문을 반복하지 않고
  `몇 사람만 거치면` 정도로만 가볍게 설명한다.

### 02 · 로그인 · 표시 이름 (`/login`)
**목적**: 동일 인물을 하나의 계정으로 식별하고, 다른 사람이 알아볼 이름을 받는다.

로그인 전:
```
🍊
먼저, 나를 알려주세요
내가 아는 사람들과 이어지려면
로그인이 필요해요.
[ 카카오로 계속하기 ]
로그인은 나를 구분하기 위해서만 사용해요.
```
로그인 후, 표시 이름 미설정:
```
🍊
어떤 이름으로 불릴까요?
아는 사람에게 보여줄 이름을 적어주세요.
[ 이름 또는 닉네임 입력칸 ]
[ 이 이름으로 시작하기 ]
실명이 아니어도 괜찮아요.
```
- 카카오 로그인은 실제 `accounts.kakao.com`으로 리다이렉트되는 것까지 확인했다.
- 이미 표시 이름까지 설정된 세션으로 이 주소에 오면 06으로 자동 이동한다.
- 지인/공개 링크에서 로그인한 경우 `returnTo`로 원래 링크를 보존한다. 표시 이름
  설정이 필요하면 완료한 뒤 원래 `/invite/{token}` 또는 `/r/{token}`으로 자동 복귀한다.

### 03 · 지인 연결 (`/connect`)
**목적**: 실제 아는 사람에게 보낼 재사용 가능한 링크를 만든다.

```
🍊
실제로 아는 사람에게
이 링크를 보내보세요.
서로 아는 사이라고 확인하면 바로 이어져요.

[ 공유하기 ]
[ gai-ara.../invite/{token}  [복사] ]

실제로 아는 사람에게만 보내주세요.

이어진 사람 보기 →
```
- "공유하기"는 모바일에서 기기 기본 공유창을 띄우고, 지원하지 않는 환경(대부분의
  데스크톱)에서는 조용히 클립보드 복사로 대체된다 — 그래서 버튼 이름을
  "카카오톡으로 보내기"가 아니라 "공유하기"로 통일했다.
- 링크에는 확인 인원 상한이나 만료 기간을 두지 않는다. 서버의 재발급 동작은
  기존 링크를 폐기하고 새 링크를 만드는 방식으로 유지한다.

### 04 · 지인 확인 (`/invite/{token}`)
**목적**: 정말 아는 사람만 확인하게 해서 가짜 연결을 막는다.

```
🍊  ?  🍊
{표시 이름}님을 알고 있나요?
실제로 아는 사이라면 알려주세요.
[ 네, 알고 있어요 ]
잘 모르겠어요
```
- 로그인 전이면 현재 URL을 보존한 채 카카오 로그인으로 이동한다. 표시 이름이
  없으면 이름 설정을 거친 뒤 원래 `/invite/{token}`으로 자동 복귀한다.
- 링크를 만든 사람 쪽에 별도 재확인을 요구하지 않는다 — 받는 사람 한쪽 확인만
  으로 즉시 연결된다.

### 05 · 연결 완료 (`/invite/{token}`, 확인 후)
**목적**: 첫 보상을 주고 다음 확산으로 이어지게 한다.

```
🍊 ───── 🍊
{표시 이름}님과
연결됐어요.
이제 서로 아는 사이로 이어졌어요.
[ 나도 아는 사람에게 보내기 ]
이어진 사람 보기 →
```

### 06 · 내 연결 메인 (`/result`)
**목적**: 관계가 자라는 걸 한눈에 보여주는, 로그인 후 사실상의 홈.

```
○ ── 🍊(나) ── ●            ← 실제 거리 기반 대표 경로 최대 6개
여기서부터 이어져요
아는 사람들이 하나둘 참여하면
건너건너 이어진 사이도 나타나요.
[ 아는 사람에게 보내기 ]
실제로 아는 사이를 확인해요.
몇 다리인지 확인할 링크 공유하기 →
나와 건너건너 얼마나 가까운지 확인해요.
로그아웃
```
- 미니 그래프는 실제 BFS 거리 1~3을 사용하되 신원과 경로를 노출하지 않는 익명 원형
  노드만 그린다. 관계가 없으면 가짜 노드 없이 중앙의 `나`만 남는다.
- 화면 진입과 탭 focus/visible 복귀 때 최신 결과를 자동으로 다시 불러온다.
- 공유 행동을 누르면 같은 화면에서 제목·설명·`공유하기`·말줄임 URL·`복사`가 펼쳐진다.
- 로그아웃을 누르면 세션이 즉시 끊기고 01로 이동하는 것까지 확인했다.

### 07 · 공개 링크 만들기 (06 화면 안에 내장)
별도 화면이 아니라 06의 "몇 다리인지 확인할 링크 공유하기 →" 영역이 그 역할을 한다.
처음 누르면 "만드는 중…"이 잠깐 뜨고, 곧바로 공유 버튼과 링크·복사 버튼이 나타난다.

### `/connections` · 건너건너 만난 사람들
**목적**: 공개 링크로 나를 찾아온 사람들 각각과의 거리를 가지(spoke) 모양으로
보여준다(화면 목록 07-1로 문서에 추가됨).

```
건너건너 만난 사람들
지금까지 발견된 사이예요.

🍊(나)
 │
 ○ (중간 사람, 이름 없음)
 │
 ● 이름 없는 방문자
```
- 거리가 멀수록 중간에 빈 점이 늘어나는 구조를 실제로 확인함(거리 2 → 빈 점 1개).
- 못 찾은 시도가 있으면 그래프 아래 "아직 못 찾은 시도 N건" 문구가 추가된다
  (이번 테스트에는 해당 사례를 안 만들어서 화면 캡처는 못 함).
- 비어 있을 때는 "아직 발견한 사이가 없어요. 링크를 공유하면 여기서 하나씩
  나타나요."가 뜨도록 코드에 반영돼 있다(직접 화면 확인은 생략).

### 08 · 공개 링크 진입 (`/r/{token}`)
```
🍊  ?  🍊
{표시 이름}님과 나는
몇 다리 건너 아는 사이일까?
서로 모르는 사이여도
생각보다 가까울 수 있어요.
[ 몇 다리인지 확인하기 ]
```
- 링크 소유자가 표시 이름을 정했으면 개인화된 문구, 없으면 "우리, 몇 다리 건너
  아는 사이일까?"로 대체된다.
- 로그인 여부와 관계없이 08을 먼저 보여준다. 비로그인 사용자가 CTA를 누르면
  공통 `returnTo` 구조로 02(로그인·이름 설정)를 거쳐 원래 `/r/{token}`으로 복귀하고,
  CTA에서 시작된 확인 의도를 한 번만 소비해 결과를 자동 계산한다.

### 09 · 연결 발견 (`/r/{token}`, 찾음)
**핵심 WOW 화면.** 유일하게 어두운 배경으로 바뀐다.
```
[검정/남색 배경, 밝은 글씨]
생각보다
가까웠어요.
🍊 ─ ● ─ ● ─ 🍊
나              상대
두 사람을 거치면 서로 닿아요.
[ 결과 공유하기 ]
나도 시작하기
```
- 실제 3다리(중간 2명) 케이스로 확인 — 점 2개와 "두 사람을 거치면"이 정확히
  일치했다.

### 10 · 연결 미발견 (`/r/{token}`, 못 찾음)
```
🍊 ··· 🍊
아직 이어지지 않았어요.
지금까지의 연결에서는 서로를 잇는 경로를 찾지 못했어요.
내 주변의 연결이 늘어나면 결과가 달라질 수 있어요.
[ 나도 시작하기 ]
다시 확인하기
```
실패처럼 안 보이게, 다음 행동(나도 시작하기)으로 자연스럽게 이어지는 것까지
확인.

### 11 · 공유 카드 (실제 화면 아님, 링크 미리보기 메타데이터)
`/r/{token}` 링크를 카톡/메시지 등에 붙여넣었을 때 보이는 미리보기 제목·설명만
갱신했다.
```
제목: 생각보다 가까웠어요 · 가이 알아?
설명: 서로 모르는 사이여도 건너건너 연결돼 있을 수 있어요. 지금 확인해봐요.
```
실제 카드 이미지를 동적으로 만드는 기능은 아직 없고, 기존 정적 이미지를 그대로
쓴다.

### 12 · 연결된 세상 (미구현)
설계만 확정돼 있고 코드는 없다. 참여자 규모가 작을 때는 🔒 "지금은 준비 중이
에요" 잠금 화면으로, 규모가 커지면 실제 지도/그래프가 열리는 구조로 설계만
해뒀다.

## 지금 눈에 띄는 문구 검토 포인트

1. **CTA는 화면 맥락에 따라 구분하기로 확정**: 최초 방문인 01은 `시작해보기`,
   다른 사람의 경험·결과 이후 화면은 `나도 시작하기`를 쓴다.
2. **01 하단 설명은 숫자나 이론명을 노출하지 않기로 확정**: `몇 사람만 거치면`으로
   가볍게 표현하고, 메인 헤드라인과 겹치는 마지막 질문은 삭제했다.
3. **개인정보처리방침은 Instagram 관련 내용을 빼고 짧게 정리함** — 추가로
   더 줄이거나 늘릴 부분 있으면 알려줘.
