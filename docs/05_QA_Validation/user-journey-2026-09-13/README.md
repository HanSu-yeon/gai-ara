## 화면 08 개정 후 캡처 상태

`08-public-entry.png`와 `08b-public-entry-unconnected.png`는 이번 개정 전에 만든 파일이다.
PNG 파일 자체는 수정하지 않았으며, 아래 최신 요구사항을 검증하는 근거로 사용하면 안 된다.

- 헤드라인: `{표시 이름}님과 나는 / 몇 다리 건너 아는 사이일까?`
- 표시 이름이 없을 때: `우리, 몇 다리 건너 / 아는 사이일까?`
- 서브카피: `서로 모르는 사이여도 생각보다 가까울 수 있어요.`
- CTA: `몇 다리인지 확인하기`
- 헤더: 로고만 표시하고 `처음으로` 행동은 숨김
- 일러스트: 화면 08에서만 개정 전보다 약 12.5% 축소

최신 390 × 844 화면의 새 시각 캡처는 아직 필요하다. 실제 카카오 로그인·이름 설정 뒤
원래 `/r/{token}`으로 복귀해 결과가 자동 계산되는 흐름도 새 브라우저 QA에서 확인해야 한다.

## 흐름·문서 불일치

1. **화면 04의 비로그인 처리 — 해결**: 카카오 로그인과 표시 이름 설정을 거친 뒤
   원래 지인 링크로 복귀하도록 `returnTo`를 보존한다.
2. **화면 04 일러스트 — 해결**: `감귤 두 개 + ?`로 변경했다.
3. **화면 05 일러스트 — 해결**: `connect.png`를 사용해 감귤 두 개가 얇은 선으로 직접
   이어진 모습으로 변경했다.
4. **화면 03 복사 UI — 해결**: 말줄임한 URL 옆에 명시적인 `복사` 버튼과
   `✓ 복사됨` 피드백을 추가했다.
5. **화면 01 문서 카피 불일치 — 수정 완료**: `user_journey_flow.md`를 실제 서브카피와
   설명 카드 구성으로 갱신했다.
6. **화면 01 CTA 검토 메모 — 확정 내용 반영 완료**: 최초 방문 `시작해보기`, 다른
   사람의 경험·결과 이후 `나도 시작하기`로 문서화했다.
7. **화면 06 캡처 — 재촬영 필요**: 기존 캡처는 숫자 통계와 수동 새로고침이 있던 이전
   구현이다. 현재는 실제 BFS 거리 기반 미니 그래프와 자동 focus/visibility 갱신을
   사용한다. 최신 390 × 844 기본·공유 펼침·관계 없음 상태를 다시 캡처해야 한다.
8. **화면 07-1 관찰 시점**: 공개 링크 방문 결과가 기록되기 전에 열면 빈 상태가 나온다.
   발견 결과가 기록된 뒤 소유자 세션에서 다시 열어야 가지형 결과를 볼 수 있다.
