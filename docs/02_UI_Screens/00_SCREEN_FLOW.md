## 사용자 흐름
- 일반 방문: 연결에 대한 기대 → 인스타 파일 받기 → 준비 순서와 선택값 → Instagram → 파일 선택.
- 초대 방문: 링크를 만든 사람과의 연결 기대 → 연결 확인하기 → 동일 안내. 연결 그림에는 예시임을 명시한다.
- 요청 전: 요청 → 알림 → 가져오기 순서를 보여주고 즉시 준비되지 않을 수 있음을 알린다. 별도 체크리스트 화면은 추가하지 않는다.
- 선택값은 외부 이동 버튼 바로 위에 일부 정보 / 팔로워 및 팔로잉, 기간 / 전체 기간, 형식 / JSON만 표시한다.
- 복귀: 파일 받았어요? → 받은 파일 선택하기. 준비된 파일 받기 링크는 보조 행동으로 제공한다.
- 파일 보유자는 안내를 건너뛰고 파일 선택으로 이동한다.

## 데이터와 예외 상태
기존 경로별 localStorage 진행 정보와 7일 만료, 초대 맥락, 분석 이벤트를 재사용한다.
새 API·DB 변경은 없다. 파일은 .zip만 선택하고 브라우저에서 파싱한다.
분석 중에는 버튼 중복 실행을 막고 파일 확인 상태를 표시한다. 잘못된 파일은 재선택 안내,
네트워크 오류는 기존 재시도, 만료된 초대는 기존 유효하지 않은 링크 화면을 유지한다.
빈 파일 선택은 현 상태를 유지한다. 개인정보 동의의 수집 항목 설명은 축약 대상이 아니다.

## 확인 기준
메인 문구에서 ZIP·내보내기·팔로잉 데이터를 제거하고 JSON은 설정 안내에서만 쓴다.
초대의 보상이 작업 안내보다 먼저 나타나며 실제 결과를 미리 확정하지 않는다.
기존 복귀/재방문/직접 업로드 경로와 이벤트 의미를 보존한다.
Instagram 실제 캡처는 확보되지 않아 미리보기에 넣지 않았다. 가상 화면을 실제 캡처로 대체하지 않는다.

## 2026-09-13 초대 티저 부분 승인
사용자가 curious.png와 curious2.png를 비교한 뒤 첫 번째 이미지 적용에 동의했다(“ㅇㅋ”).
초대 첫 화면의 상단 이미지를 curious.png로 교체하고 예시 동그라미/연결선은 제거한다.
제목은 “우리, 몇 다리 건너 아는 사이일까?”, 버튼은 “우리 연결 확인하기”로 표시한다.
이미지는 기존 PNG를 그대로 사용하고 CSS로 외곽 여백을 줄인다. 시작 후와 실제 결과 화면은 유지한다.
이 승인은 초대 티저에 한정하며, 위의 전체 파일 가져오기 미리보기는 별도 확인 대기다.
