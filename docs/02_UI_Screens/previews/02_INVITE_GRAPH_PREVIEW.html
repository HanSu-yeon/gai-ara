TASK-003 갱신 — 로그인 · 표시 이름 · 재사용 링크
  1. 02 화면(신규) — 카카오 로그인과 표시 이름 입력을 추가했다. 동일한 사람이 여러 링크를 받아도 하나의 participant로 모이게 하기 위함이며, 화면 04의 "이 사람을 알고 있나요?"를 "{표시 이름}님을 알고 있나요?"로 바꿀 수 있게 됐다.
  2. 03 화면 — 재사용 가능한 링크로 바꾸고, 공유와 명시적 복사 행동을 분리했다. 인원 상한과 만료 기간은 두지 않는다.
  3. 04 화면 — 익명 "이 사람을 알고 있나요?"를 표시 이름이 들어간 "수연님을 알고 있나요?"로 바꿨다(예시 이름).
  4. 05 화면 — connect.png로 두 감귤이 직접 이어진 상태를 보여준다. 기본 행동은 "나도 아는 사람에게 보내기", 보조 행동은 "이어진 사람 보기 →"로 구분한다.
  5. 06·07 화면 — 07은 별도 페이지가 아니라 06의 미니 그래프를 유지한 채 펼쳐지는 상태다. 공유하기를 Primary로, URL 복사를 Secondary로 둔다.
